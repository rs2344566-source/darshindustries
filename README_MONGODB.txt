DARSH INDUSTRIES — MONGODB ENQUIRY INBOX

Start here: BACKEND_SETUP.md

Quick summary:
1. Install Node.js LTS.
2. Create a free MongoDB Atlas cluster and database user.
3. Copy .env.example to .env and fill in MongoDB URI, admin login, and JWT secret.
4. In a terminal opened in this folder run: npm install
5. Then run: npm start
6. Open http://localhost:3000/html/contact.html to submit a test enquiry.
7. Open http://localhost:3000/html/admin.html to sign in and view it.

Use the Express server (localhost:3000), not Live Server, for the contact form and inbox.
Email replies require SMTP credentials in .env. Do not share or publish .env.
